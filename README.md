# Peste Negra: Pandemia

Jogo 2D de cima em HTML, CSS e JavaScript puro. Você é a Yersinia pestis no meio da guerra.

## Como rodar
- Abra `index.html` no navegador, ou
- No VS Code, instale a extensão **Live Server**, clique com o botão direito em `index.html` e escolha **Open with Live Server**.

## Estrutura
- `index.html`: página e canvas
- `css/style.css`: estilos e menus
- `js/game.js`: toda a lógica do jogo

## Controles
WASD/setas mover · Mouse/Espaço atirar · Q sair do corpo · E evoluir · 1/2/3 cepas · Z/X/C/V habilidades · Esc pausar
